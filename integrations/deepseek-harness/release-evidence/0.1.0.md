## Privacy and unload boundary

- Capture and retrieval are independent explicit opt-ins; the default Bundle row is inert.
- Retrieval accepts only verified, active, promoted memory from a complete portable repository and fails open without stale or partial fallback.
- Raw Harness events, prompts, model output, locally exposed reasoning, tool calls, tool results, and session artifacts remain local and are excluded from Git, npm, and GitHub Release assets.
- Unsupported persistence, unknown events, malformed records, and projection failures remain explicit gaps.
- The repository is discoverable through the `dsh-plugin` and `deepseek-harness` topics.
